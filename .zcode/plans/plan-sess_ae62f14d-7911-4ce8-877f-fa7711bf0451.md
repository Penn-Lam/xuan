# xuan（宣）— 实施计划

## 核心设计哲学

> **导出格式 = 文件格式 = Agent 操作格式。** 三者同构。

infourier 的导出 JSON 本身就是天然的 "focused format"（tldraw 概念）——扁平、语义清晰、zod 校验。xuan 把这个格式提升为**一切的契约**：人用 Web UI 编辑、Agent 用 CLI 操纵 .json 文件、AI 用同一份 JSON 生成代码。三者在同一个 schema 上交汇，无需翻译层。

**沿用 infourier 的双引擎**：
- **IA 模式** = React Flow + `d3.tree()`（擅长树形思维导图）
- **Canvas 模式** = 手写嵌套绝对定位 div（擅长父子包含 + 像素级布局）
- **桥梁** = `materialize()`：切到 Canvas 时，未放置的节点自动竖向堆入父容器
- 两模式编辑**同一棵扁平文档树**，"双向同步"因此免费

**设计系统**：遵循 `design.md`（Light）/ `design.dark.md`（Dark）的 Geist token。关键映射：
- `--background: #ffffff` / `#000000`，`--foreground: #171717` / `#ededed`
- `--primary: #171717` / `#ededed`（Geist 原色，非 infourier 的 `#0900ff`）
- `--ring: #006bff` / `#47a8ff`，`--radius: 0.375rem`（6px）
- `--border` 用 alpha 半透明值

## 文档模型（types/document.ts）— 唯一契约

内部表示（扁平树，双模式共用）：

```typescript
// 矩形
interface Rect { x: number; y: number; w: number; h: number }

// 扁平节点（内部存储）
interface FlatNode {
  id: string; parentId: string | null; childrenIds: string[]
  name: string; role: string                    // 语义角色（page/header/card/...）
  component: { ref: string; props: Record<string, any> } | null  // shadcn 绑定
  content: Record<string, any> | null           // 内容意图
}

// 文档（单一真相源）
interface Document {
  version: "2.0"
  meta: { name: string; designSystem: string; viewport: { width: number; height: number } }
  rootId: string
  nodes: Record<string, FlatNode>               // 扁平 map
  canvas: Record<string, { rect: Rect; shape: "rectangle"|"ellipse"|"text"; placed: boolean }>
  mindmap: Record<string, { collapsed: boolean }>
}
```

导出/文件格式（嵌套树，绝对坐标）— **= Agent 工作格式 = AI 输入**：

```typescript
// Zod 校验的递归 schema
const Node = z.lazy(() => z.object({
  id: z.string(), name: z.string(), role: z.string(),
  rect: Rect, shape: z.enum(["rectangle", "ellipse", "text"]),
  component: z.object({ ref: z.string(), props: z.record(z.any()) }).nullable(),
  content: z.record(z.any()).nullable(),
  children: z.array(Node)
}))
const ExportDoc = z.object({
  version: z.literal("2.0"),
  meta: z.object({ name: z.string(), designSystem: z.string(), viewport: z.object({...}) }),
  tree: Node
})
```

## 实施阶段

### Phase 1：基础骨架 + 最小可运行闭环（先重构出能跑的 infourier）

> 目标：项目跑起来，能画树、能切 Canvas、能导出 JSON。每步可验证。

1. **脚手架**
   - `npm create vite@latest . -- --template react-ts`
   - 装 Tailwind v4：`@tailwindcss/vite` + `@import "tailwindcss"`
   - `npx shadcn@latest init`（new-york / neutral / cssVariables）
   - 装依赖：`@xyflow/react` `zustand` `immer` `zod` `nanoid` `d3-hierarchy` `sonner` `@phosphor-icons/react` `@fontsource-variable/geist` `@fontsource-variable/geist-mono`
   - `index.css`：写入 Geist Light/Dark CSS 变量（来自 design.md），`@theme` 设 `--font-sans/--font-mono`
   - `main.tsx`：加载 Geist 字体 + `<IconContext.Provider value={{weight:"light"}}>` + `<TooltipProvider>`
   - 写 `src/CLAUDE.md` 记录架构

2. **文档模型**（`types/document.ts` + `lib/` + `model/factories.ts`）
   - 定义类型 + Zod schema
   - `id.ts`、`geometry.ts`（clampRect/absoluteRect/isDescendant）
   - `createBlankPage(viewport)`、`createDefaultDocument()`（Operations Dashboard 示例）

3. **Zustand store**（`store/useEditorStore.ts` + `store/undo.ts`）
   - state：`document` `pages` `activePageId` `mode` `selectedId` `past` `future`
   - 基础 action：`addNode` `removeNode` `renameNode` `setRole` `setComponent` `setContent` `selectNode` `setMode`
   - immer 中间件 + patch undo/redo + persist（localStorage，partialize pages + activePageId）

4. **App shell**（`App.tsx` + `components/shell/`）
   - 三栏布局：header（h-14）+ main（左画布 + 右 292px Inspector）
   - Header：名称输入 + IA/Canvas Tabs + 导入按钮 + 导出下拉

5. **IA 模式基础**（`components/mindmap/`）
   - React Flow 容器，`d3.tree().nodeSize([104,284])` 计算位置
   - 自定义 `MindmapNode`（白卡片，显示 name + role badge）
   - 从 store 读 document → 生成 RF nodes/edges
   - 选中节点 → 选中写回 store

6. **Canvas 模式基础**（`components/canvas/`）
   - 嵌套绝对定位 div 渲染（`absoluteRect` 求绝对坐标）
   - 选中高亮 + Inspector 联动
   - 页面 frame（root 节点 = viewport 尺寸的画板）

7. **materialize 桥梁**（`model/materialize.ts`）
   - 切到 Canvas 时跑一次，把未放置节点竖向堆入父容器

8. **导入/导出**（`model/serialize.ts` + `deserialize.ts`）
   - Export JSON（嵌套 + 绝对坐标，zod 校验）→ 复制到剪贴板 + 下载 .json
   - Import JSON（校验 → 反序列化回扁平模型）

9. **Inspector 基础**（`components/inspector/`）
   - Basics（名称/role/shape）+ Component（shadcn 绑定下拉 + props JSON）+ Content（JSON）

**Phase 1 验收**：能加载默认 Dashboard 文档，IA 看到树、Canvas 看到布局，选中节点改属性，导出 JSON。

> 目标：在重构基础上实现你要的扩展。

1. **i18n 中英文切换**（`i18n/`）
   - `useTranslation()` hook，localStorage 存语言偏好

2. **Inspector 内嵌 shadcn 实时预览**（`components/inspector/NodePreview.tsx`）

   - role 提供布局骨架（如 `card` → Card 组件框架），component 填充实际控件

   - `xuan new <name>` — 创建空白 .json 文档

   - `xuan bind <file> --node <id> --component Button --props '{"variant":"outline"}'` — 绑组件

   - 输出友好的树形 JSON，让 Agent 一眼读懂结构

**Phase 3 验收**：中英文切换生效，Inspector 预览实时渲染 shadcn，CLI 能完整操控 .json 文档。

## 关键设计决策（为何如此）

1. **导出格式 = Agent 格式**：CLI 直接读写嵌套树 JSON，Web App 导入导出同一格式。零翻译层。这是 tldraw "focused format" 思路的简化版——infourier 的 schema 已经足够简洁。

2. **扁平内部模型 + 双模式免费同步**：两模式共享一个 `nodes` map，`canvas[id]` 和 `mindmap[id]` 是正交侧表。改一边另一边立即可见，无需同步逻辑。

3. **model/ 层无 React 依赖**：`materialize`/`serialize`/`factories` 是纯函数，CLI 可直接复用。避免逻辑耦合到 UI。

4. **persist 只存 pages + activePageId**：不持久化 undo 历史、selection、viewport——这些是会话态。

5. **Phosphor 替换 lucide**：infourier 用 lucide-react，xuan 统一用 Phosphor（`weight: "light"` 全局）。shadcn 组件内的图标需手动替换。

6. **Geist 原色而非 infourier 的 `#0900ff`**：遵循 design.md，`--primary` 用 `#171717`/`#ededed`。
